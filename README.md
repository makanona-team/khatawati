# خطواتي (Khatawati)

تطبيق أندرويد لعدّ خطوات المشي ومسافته فقط، مع سجل منفصل لرحلات السيارة، ومواقيت الصلاة والأذان، وويدجت.

- التحميل: [آخر إصدار](https://github.com/makanona-team/khatawati/releases/latest)
- البيانات محفوظة على الهاتف فقط.
- كل إصدار يُبنى ويُنشر تلقائياً عند تغيير `versionName` في `app/build.gradle`، وملاحظاته في `changelogs/<الإصدار>.md`.
